Default client IPv6 routes
IPv6 forwarding is opt-in. IPv6 client routes require an IPv6 tunnel range and client address, plus working routed IPv6 egress. Linux applies forwarding globally; disabling this network leaves it enabled. NAT66 is not used.

A routed LAN forwards authorized client traffic to the approved downstream prefixes only, never masquerades, and is implemented on macOS only. The filter that bounds it is operator-managed: the product reports the exact rules it observed and refuses to converge when they are missing or have drifted.
